## Requisitos não funcionais
Esses requisitos descrevem **como** o sistema deve funcionar:
- funcionar offline;
- armazenar dados localmente;
- O processo de importação deverá ser concluído em tempo adequado para arquivos de tamanho comum. Até 3 segundos para arquivos com até 10.000 registros.
- A interface deverá priorizar simplicidade e facilidade de navegação.
- executável para Windows e Linux.
