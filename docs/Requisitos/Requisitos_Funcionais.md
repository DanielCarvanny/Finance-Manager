## Requisitos  funcionais
- O sistema deverá receber o csv e categorizar automaticamente as movimentações.
- O sistema deverá validar o formato do arquivo antes da importação.
- O sistema deverá armazenar as movimentações importadas.
- O sistema deverá categorizar automaticamente as movimentações.
- O sistema deverá permitir edição manual das categorias.
- O sistema deverá calcular indicadores financeiros.
- O sistema deverá apresentar gráficos e relatórios.
