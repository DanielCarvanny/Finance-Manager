## O que é o projeto?
Um projeto de um software desktop de análise financeira de gastos mensais que lida com informações de extrato bancário para organização financeira de forma automatizada.

## Objetivo do projeto
- importar extratos bancários;
- organizar despesas;
- calcular indicadores financeiros;
- categorizar movimentações;
- apresentar um dashboard;
- funcionar como um software desktop.

## Público-alvo
- será um sistema de uso pessoal;
- inicialmente terá apenas um usuário;
- funcionará localmente.
